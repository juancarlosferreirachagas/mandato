# Regras editoriais

1. **Fato → Fonte → Interpretação.** Todo fato aponta para uma fonte. Interpretação é separada e identificada como tal.
2. **Nunca inventar dados.** Sem fonte, não entra.
3. **Sem julgamento automático.** Proibido classificar político como “bom”, “ruim”, “corrupto”, “extremista” etc.
4. **Informação controversa** (processos, decisões) deve conter: fato, fonte, contexto, posição declarada pelo político/órgão, contrapontos e situação atual.
5. **Promessas**: o texto é registrado literalmente; a avaliação exige status, justificativa e fonte própria.
6. **Métricas** sempre exibem o período analisado e são calculadas a partir dos registros.
7. **Correções** passam pelo admin e ficam em `audit_log`.
8. **Ausência de dado ≠ ausência de ação.** A UI deve dizer “sem registros importados”, não “não fez”.
9. **Processos**: indicar se há trânsito em julgado; não tratar acusação como condenação.
